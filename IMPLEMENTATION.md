# Implementation plan

1. Application shell, responsive design, navigation and explicit demo boundary.
2. Supabase sessions, onboarding, eight core tables, RLS, private storage and atomic quotas.
3. Server-only YouCam submission, bounded recoverable polling, validated parsing and transactional persistence.
4. Dashboard, results, history, deterministic comparisons and missing-data states.
5. Experiment creation, usage records, baseline comparison and status controls.
6. Modular grounded LLM insights with per-user sharing consent and deterministic fallback.
7. Privacy deletion, configurable retention, tests, production build and deployment documentation.

Live acceptance must be verified against configured Supabase and YouCam accounts; synthetic demo data is never a substitute for this verification.
